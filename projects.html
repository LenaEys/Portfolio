Selected work

Projects

Six projects spanning lab instrumentation, biomechanics research, assistive robotics, and personal CAD work.

Trip-Perturbation Device

Independently designed and built a prototype flip-up tripping barrier for trip-perturbation experiments, triggerable by either computer or forceplate input. Covered the full pipeline: bill of materials, torque calculations for the barrier's weight, Arduino coding, circuit design through breadboard integration, and iterative troubleshooting with a multimeter — completed in 75% of the allotted timeframe, at Wilfrid Laurier's Neuromechanics Lab.

Footwear Biomechanics Research

Analyzed data from in-ground force plates, a load cell and oscilloscope setup, and an OptiTrack 3D marker system to find shoe-ground and insole-fabric coefficients of friction, and to track peak moments as footwear underwent torsion and bending. Filtered and graphed all datasets and summarized findings in a final report used to build a reference set of footwear properties for future papers.

Haptic Vision — UTESCA

Contributed to UTESCA's Haptic Vision project, a robotic solution helping visually impaired users interact with digital platforms. Used Python and Unity to convert 2D user interfaces into 3D models ready for integration with existing robotic prototypes. The project went on to win the 2026 Troost ILead Difference Maker Award and a $50,000 scholarship.

Arduino Coding Box, WiSTEM

Designed the housing for an introductory Arduino coding box built to promote coding among women, presented at a Laurier WiSTEM event. Also tutored students in SolidWorks and Arduino coding — within a week, tutees completed CAD training and wrote their own stepper-motor movement patterns.

Prosthetic Wrist, CAD

A personal SolidWorks project modelling a prosthetic wrist mechanism — part of a set of self-directed CAD work that also included a storage-room renovation model and a set of custom Arduino characters.

Automated Re-Centering Fan

A personal electronics project programming a motor that automatically re-centers itself paired with a fan that activates on its own — built to practice Arduino motor control and sensor-triggered logic outside of coursework.
